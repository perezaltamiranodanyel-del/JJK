# 🚀 Proyecto Web: Soluciones Digitales

Sitio web en desarrollado como proyecto final, aplicando estructuras avanzadas de desarrollo web frontend, semántica estricta y diseño responsivo.

## 🛠️ Tecnologías y Herramientas Utilizadas
- **HTML5** (Semántica, SEO local y accesibilidad).
- **CSS3 / SCSS** (Arquitectura con partials, variables, mixins, nesting y `@use`).
- **Bootstrap 5.3** (Componentes responsivos y grillas).
- **AOS (Animate On Scroll)** (Animaciones externas).
- **Git y GitHub** (Control de versiones).

## 📂 Estructura del Proyecto
- `index.html` (Página principal en la raíz).
- `pages/` (Contiene las vistas secundarias: `servicios.html`, `contacto.html`, `proyectos.html`, `sobre-mi.html`).
- `scss/` (Archivos fuente de estilos organizados por partials).
- `styles/` (CSS compilado).
- `imagen/` (Recursos multimedia y logotipos del sitio).
